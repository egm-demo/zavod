## 1. Технические правила
- Подключи общую базу в `<head>` (пути относительные, работают и на GitHub Pages, и офлайн):
  `<link rel="stylesheet" href="../../assets/fonts/fonts.css"><link rel="stylesheet" href="../../assets/ui.css">`
  Google Fonts по сети больше НЕ подключать (шрифты лежат локально: Cormorant Garamond 400/500/600 + italic, Manrope 400–700, кириллица).
  Прочитай `C:/Users/maya/mama-apps/assets/ui.css` целиком и используй его токены и классы (`--bg --ink --ink-2 --ink-3 --accent --glow --leaf --line --surface`, `.z-app .z-top .z-icon .z-h1 .z-lead .z-cap .z-btn .z-bar .z-tool .z-seg .z-sheet .z-scrim .z-dialog .z-toast .z-in`). ui.css НЕ редактируй (он общий для 20 приложений); свои стили — в своём файле.
- Сохрани блок `<!--pwa-->...<!--/pwa-->` из старого файла как есть (для новых приложений скопируй его из любого старого app-файла; родитель потом пересоберёт sw.js).
- Без внешних JS-библиотек и CDN. Графика — Canvas 2D / WebGL (сам, без three.js) / SVG, нарисованные кодом. Без эмодзи. Без картинок-файлов (кроме `icon.svg`, см. ниже).
- Mobile-first: 360x780 и 402x874, safe-area, хит-зоны ≥ 44px, нет горизонтального скролла (`scrollWidth <= innerWidth` на ВСЕХ экранах, включая игровые и итоговые), canvas с devicePixelRatio (до 2–3), без размытия. Десктоп: колонка по центру до 520px.
- Звук: только WebAudio-синтез, только после касания, кнопка выключения, состояние mute помни в localStorage (новый ключ можно).
- Тактильность: `navigator.vibrate?.(8)` на ключевых действиях (выкл. вместе со звуком).
- `prefers-reduced-motion` уважать. 60 fps: не перерисовывай всё без нужды, останавливай rAF, когда вкладка скрыта.
- 0 ошибок в консоли (ошибки про manifest на file:// — допустимы, это норма).

## 2. Дизайн-язык v2 (главное)
- **Минимализм интерфейса:** на экране одно главное действие. Верхняя строка `.z-top`: слева иконка «назад» (шеврон, ведёт `../../index.html`, aria-label «Все приложения»), по центру короткое название или пусто, справа максимум 1–2 иконки (звук / меню-шторка). Всё вторичное (правила, настройки, статистика, сброс) — в шторку `.z-sheet` по иконке. Никаких стен текста: правила — 1–3 короткие строки или показать анимацией при первом входе.
- **Без рамок-коробок.** Не обводить всё тонкими бордерами. Иерархия — размером, весом, воздухом, тоном фона. Карточки — только тональные (`--surface`).
- **Один акцент на экран** — розовый `--accent`; золото `--glow` только как свет (светлячки, фонари), не как цвет кнопок.
- **Типографика:** заголовки Cormorant (400/500, курсив для акцентного слова), текст Manrope 15–17px, подписи `.z-cap`. Цифры `tabular-nums`. `text-wrap: balance/pretty`. Минимум мелкого серого текста; вторичный текст не бледнее `--ink-2` если его нужно читать.
- **Графика — это главное в «улучши графику»:** глубина и свет. Мягкие тени, объём (градиенты по форме, блики, внутренняя тень), лёгкая анимация «дыхания» мира (вода колышется, светлячки, отражения), частицы при успехе, плавные easing-переходы (`--ease`), микро-анимации нажатий. Вода — с рябью/каустикой/отражением, листья — с прожилками и тенью на воде, кувшинки — многослойные лепестки с градиентом. Рисуй процедурно и красиво, не «квадратики-заглушки».
- **Палитра:** ночной пруд (`--bg #0a1416`), сливочный текст, пудрово-розовый акцент, лист, золото света, фиолетово-чёрный (`--violet`) для «пикниковых» мистических вещей. Можно менять настроение под приложение (например, тёплый песок для сада камней), но оставаться в семье.
- **Экран победы/итога:** не модалка-коробка, а событие: мир реагирует (кувшинки распускаются, свет вспыхивает), потом спокойный текст и одна кнопка «Дальше».
- **Онбординг:** при самом первом входе (новый ключ `kuv_<slug>_v2_seen`) — одна подсказка-жест или 1 строка, исчезает сама. У мамы, у которой уже есть прогресс, тоже показать один раз «что нового» одной строкой — ненавязчиво.
- **Иконка приложения:** создай `apps/<slug>/icon.svg` — viewBox 0 0 64 64, БЕЗ фона (прозрачный), линейная графика: штрих `#f3ece0` 1.6px round, плюс ОДНА деталь-заливка акцентом (`#efb3c1` или `#e8c77a` для света). Простая, узнаваемая, в одном стиле со всеми. Это для главной страницы.
